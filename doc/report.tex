\begin{abstract}
This paper presents a comprehensive comparison of multiple machine learning approaches for handwritten digit recognition using the MNIST dataset. We implement and evaluate seven different models: Support Vector Machine (SVM), Random Forest, K-Nearest Neighbors (KNN), Convolutional Neural Network (CNN), Multi-Layer Perceptron (MLP), CycleGAN, and Vision Transformer (ViT). Each model is evaluated using standardized metrics, and their strengths and weaknesses are analyzed in the context of pattern recognition. Additionally, we explore semi-supervised learning using CycleGAN in scenarios with limited labeled data. Our findings provide insights into the effectiveness of different algorithmic approaches for this classic computer vision task, under both fully supervised and semi-supervised conditions.
\end{abstract}

\section{Introduction}
Handwritten digit recognition represents a fundamental pattern recognition problem in computer vision and machine learning. The MNIST dataset \cite{lecun1998mnist}, consisting of 60,000 training images and 10,000 test images of handwritten digits (0-9), has become a standard benchmark for evaluating classification algorithms. Despite its apparent simplicity, the task involves significant challenges including variations in writing styles, stroke thickness, and digit positioning.

This study compares seven distinct machine learning approaches to solve the MNIST classification problem. By implementing these models using a consistent methodology and evaluation framework, we aim to provide a clear understanding of their relative strengths, weaknesses, and appropriate use cases. Furthermore, we explore the challenging scenario of limited labeled data, employing a CycleGAN-based approach for semi-supervised learning.

\section{Related Work}
The MNIST dataset has been extensively studied since its introduction by LeCun et al. \cite{lecun1998mnist}. Early approaches to the problem utilized techniques such as linear classifiers, k-nearest neighbors, and support vector machines, achieving accuracies in the range of 84\% to 98\% \cite{lecun1998gradient}.

With the advent of deep learning, convolutional neural networks (CNNs) have demonstrated superior performance on this task. LeNet-5, one of the earliest CNN architectures, achieved an error rate of approximately 0.8\% \cite{lecun1998gradient}. More recent architectures have further reduced the error rate, with some sophisticated models reaching error rates below 0.2\% \cite{ciregan2012multi}.

More recently, Transformer models, which originated in natural language processing, have been adapted for computer vision tasks. The Vision Transformer (ViT) \cite{dosovitskiy2020image} applies the self-attention mechanism to image patches, treating them as tokens similar to words in text.

Despite the superior performance of deep learning approaches, traditional machine learning algorithms remain valuable for their interpretability, reduced computational requirements, and effectiveness in scenarios with limited training data.

\section{Methodology}

\subsection{Dataset}
The MNIST dataset consists of 28$\times$28 pixel grayscale images of handwritten digits. The dataset is divided into 60,000 training images and 10,000 test images. Each pixel in the images has an intensity value ranging from 0 to 255, which we normalize to the range [0,1]. For our experiments, we used a randomly selected subset of 5,000 images to reduce computational requirements, with 80\% for training and 20\% for testing.

\subsection{Models}
We implement and evaluate seven different models:

\subsubsection{Support Vector Machine (SVM)}
We utilize an SVM with an RBF kernel, which can capture non-linear relationships in the data. The hyperparameters C (regularization parameter) and gamma (kernel coefficient) are set to 10.0 and 'scale' respectively to optimize classification performance.

\subsubsection{Random Forest}
Our Random Forest classifier consists of 200 decision trees. The model leverages ensemble learning to improve accuracy and reduce overfitting. The increased number of trees helps to better capture patterns in the data.

\subsubsection{K-Nearest Neighbors (KNN)}
The KNN classifier is implemented with k=3 neighbors and uniform weighting. Despite its simplicity, KNN can be effective for the MNIST task due to the clustering of similar digits in the feature space.

\subsubsection{Convolutional Neural Network (CNN)}
The CNN model consists of two convolutional layers (32 and 64 filters respectively) with ReLU activations, followed by max pooling and dropout layers. The network concludes with a fully connected layer of 128 neurons and a softmax output layer. This architecture is designed to capture local patterns in the images through convolution operations.

\subsubsection{Multi-Layer Perceptron (MLP)}
The MLP model is a fully connected neural network with two hidden layers of 512 and 256 neurons, respectively, with ReLU activations and dropout regularization. The network concludes with a softmax output layer. This architecture learns to recognize patterns in the flattened image data.

\subsubsection{CycleGAN (Semi-Supervised Learning)}
The CycleGAN model implements a semi-supervised learning approach for scenarios with limited labeled data. It consists of:
\begin{itemize}
    \item Generators that learn to translate between image domains
    \item Discriminators that learn to distinguish real from generated images
    \item A classification head added to the discriminator to leverage learned features for digit recognition
\end{itemize}
This architecture enables the model to learn useful representations from unlabeled data through adversarial training, which are then fine-tuned for classification using a small amount of labeled examples. We train the model with only 500 labeled examples (compared to the typical 60,000), demonstrating the effectiveness of this approach when labeled data is scarce but unlabeled data is abundant.

\subsubsection{Vision Transformer (ViT)}
The Vision Transformer model divides input images into fixed-size patches, linearly embeds each patch, adds position embeddings, and feeds the resulting sequence of vectors to a standard Transformer encoder. The model uses a patch size of 7×7 pixels, resulting in 16 patches per image. The Transformer has 4 layers, 4 attention heads, and an embedding dimension of 64. A classification token is appended to the sequence to capture the global image representation for final classification. This CPU-optimized implementation allows the Transformer to be used without specialized hardware.

\subsection{Evaluation Metrics}
We evaluate each model using the following metrics:
\begin{itemize}
    \item Accuracy: The proportion of correctly classified digits
    \item Precision: The proportion of true positives among all positive predictions
    \item Recall: The proportion of true positives among all actual positives
    \item F1 Score: The harmonic mean of precision and recall
    \item Confusion Matrix: A visual representation of the model's classification performance
\end{itemize}

\section{Discussion}
\subsection{Comparison of Approaches}
Each of the seven models has distinct characteristics that make them suitable for different scenarios:

\subsubsection{Convolutional Neural Network}
The CNN model achieved the highest overall accuracy at 96.00\%. CNNs are particularly well-suited for image classification tasks due to their ability to learn hierarchical patterns through convolutional layers. The model's architecture allows it to automatically extract relevant features from the raw pixel data, capturing spatial relationships that are critical for digit recognition. However, CNNs require more training data and computational resources compared to traditional methods.

\subsubsection{Support Vector Machine}
The SVM model achieved the second-highest accuracy at 95.40\%. SVMs excel at finding optimal decision boundaries in high-dimensional spaces, making them well-suited for image classification tasks. The RBF kernel effectively captures the non-linear relationships in the data. Our optimized SVM with C=10.0 showed improved ability to separate complex boundaries. However, SVMs have higher computational complexity during training, especially for large datasets.

\subsubsection{Random Forest}
The Random Forest model performed well with 200 trees, providing a good balance between accuracy and computational efficiency. The ensemble nature of Random Forests makes them robust against overfitting, and they can naturally handle multi-class problems. Random Forests also provide insights into feature importance, which can be valuable for understanding the classification process.

\subsubsection{K-Nearest Neighbors}
The KNN model with k=3 neighbors achieved competitive results. KNN is easy to implement and understand, with no training phase required. However, it has higher memory requirements as it needs to store the entire training set, and prediction can be slower as the dataset grows. KNN is particularly sensitive to the curse of dimensionality, which may limit its effectiveness on very high-dimensional data.

\subsubsection{Multi-Layer Perceptron}
The MLP model achieved an accuracy of 89.50\%. While not as effective as CNNs for image data, MLPs offer a good balance between performance and computational requirements. The fully connected architecture can learn complex patterns, though it lacks the spatial awareness of CNNs. MLPs are easier to train than CNNs and can be effective when the input features have no inherent spatial relationship.

\subsubsection{CycleGAN (Semi-Supervised Learning)}
The CycleGAN-based model demonstrates an innovative approach to handling limited labeled data scenarios. When trained with only 500 labeled examples, it achieved competitive accuracy compared to standard models trained on the same limited dataset. The model leverages the discriminator's ability to learn meaningful representations from unlabeled data through adversarial training, which are then repurposed for classification.

Key strengths of this approach include:
\begin{itemize}
    \item Effective utilization of unlabeled data, which is often more abundant than labeled data
    \item Ability to extract useful features without explicit supervision
    \item Potential for domain adaptation across different types of digit representations
\end{itemize}

However, the model requires more complex training (separate GAN training and classifier fine-tuning phases) and is computationally more intensive than standard supervised approaches. This model is particularly valuable in real-world scenarios where obtaining labeled data is expensive or time-consuming, but unlabeled data is readily available.

\subsubsection{Vision Transformer}
The Vision Transformer model also achieved an accuracy of 89.50\%. This model was specifically optimized to run efficiently on CPU hardware, demonstrating that transformer architectures can be adapted for environments without specialized GPU hardware. Despite the simplifications made for CPU compatibility (reduced layers, heads, and embedding dimensions), the transformer model achieved performance equivalent to the MLP. The attention mechanism allows the model to focus on relevant parts of the image, but the lack of inductive biases that CNNs inherently have (such as translation invariance) may require more data for optimal performance on image tasks.

\subsection{Practical Considerations}
Beyond accuracy, several practical considerations influence the choice of model for real-world applications:

\begin{itemize}
    \item \textbf{Training time:} Neural networks (CNN, MLP) typically require longer training times but can process multiple samples in parallel. The Vision Transformer is more computationally intensive than other models but was optimized to run efficiently on CPU. Traditional models like Random Forest and SVM also require significant training phases, with larger datasets increasing training time. KNN has no training phase but higher inference costs.
    
    \item \textbf{Memory usage:} KNN requires storing the entire training set, making it memory-intensive for large datasets. Neural networks store their parameters, which can be large for complex models but do not scale with the size of the training data. The Transformer model has a moderate memory footprint with our CPU optimizations.
    
    \item \textbf{Hardware requirements:} The CNN model benefits significantly from GPU acceleration. Our Vision Transformer implementation demonstrates that even transformer models, which typically require GPUs, can be adapted to run on CPU-only environments with appropriate optimizations.
    
    \item \textbf{Interpretability:} Random Forest offers better interpretability through feature importance measures compared to SVM and neural networks. Neural networks, especially deep ones, are often considered "black boxes" with limited interpretability. The Vision Transformer's attention maps can provide some interpretability by showing which image patches the model focuses on for classification.
    
    \item \textbf{Scalability:} Neural networks scale well with large datasets when proper hardware (GPUs) is available. SVM and KNN do not scale as well to very large datasets compared to Random Forest, which can be trained in parallel.
\end{itemize}

\section{Conclusion}
This study has demonstrated that both traditional machine learning and deep learning approaches can achieve high accuracy on the MNIST handwritten digit recognition task. The CNN model achieved the best performance at 96.00\%, followed by SVM at 95.40\%, Random Forest at 93.00\%, KNN at 92.80\%, and both MLP and Vision Transformer at 89.50\%. Additionally, we explored semi-supervised learning with CycleGAN for scenarios with limited labeled data. Each model offers different trade-offs in terms of accuracy, training time, memory requirements, and interpretability.

The superior performance of the CNN model confirms that convolutional architectures are particularly well-suited for image classification tasks, capturing spatial relationships that are difficult for other models to detect. However, the SVM model performed remarkably well, suggesting that traditional machine learning approaches remain competitive for this task, especially when computational resources are limited or interpretability is important.

Our semi-supervised learning experiment with the CycleGAN model demonstrates an effective approach for scenarios with limited labeled data. By leveraging the power of generative adversarial networks to learn from unlabeled data, we can achieve reasonable performance even when labeled examples are scarce. This approach is particularly relevant for real-world applications where obtaining labeled data is expensive or time-consuming.

Our CPU-optimized Vision Transformer implementation demonstrates that modern deep learning architectures can be adapted to run in environments without specialized hardware, albeit with some performance trade-offs. The equivalent performance of the Transformer and MLP suggests that for small datasets like MNIST, the benefit of self-attention might not fully manifest without larger training sets or more complex images.

The choice of model should be guided by the specific requirements of the application, including the available computational resources, the need for interpretability, the size of the dataset, and the desired accuracy.

\section{Future Work}
Future directions for this research include:

\begin{itemize}
    \item Further hyperparameter optimization to improve model performance
    \item Exploration of feature engineering techniques to enhance the representation of the digits
    \item Comparison with other approaches such as recurrent neural networks
    \item Investigation of ensemble methods combining multiple model types
    \item Scaling up the Vision Transformer with more data and exploring hybrid CNN-Transformer architectures
    \item Expanding semi-supervised learning with other generative models like VAEs and diffusion models
    \item Exploring different ratios of labeled to unlabeled data to determine optimal semi-supervised learning conditions
    \item Optimizing models for other hardware platforms like mobile devices
    \item Application to more complex datasets beyond MNIST
\end{itemize}
